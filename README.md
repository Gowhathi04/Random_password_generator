# Random Password Generator

## Project Description
This is a simple Python Random Password Generator project that creates secure and random passwords based on user requirements.

The program generates passwords using combinations of letters, numbers, and special characters to improve security.

## Features
- Generates random passwords
- User can choose password length
- Includes uppercase and lowercase letters
- Includes numbers and special symbols
- Easy to run and beginner-friendly

## Technologies Used
- Python
- Random Module
- String Module

## How It Works
1. User enters desired password length
2. Program randomly selects characters
3. Password is generated and displayed

## How to Run
1. Install Python
2. Open terminal or VS Code
3. Run:

```bash
python password_generator.py
```

## Example Output

Enter password length: 10

Generated Password:
A@8kP#2mL!
